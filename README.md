# Farhan Zaman — Portfolio

Personal portfolio for Farhan Zaman, a software engineer working across machine learning, backend infrastructure, and full-stack product development.

**Live site:** [farhanzaman.net](https://farhanzaman.net/)

## Overview

The site presents my professional background, selected software and machine-learning projects, work experience, education, and current work with Delvian Studio. It is a responsive, single-page website built without a frontend framework or build step.

## Highlights

- Responsive hero, about, selected work, experience, studio, and contact sections
- Project case studies with screenshots, outcomes, technology tags, and external links
- Horizontally scrollable experience cards with keyboard-accessible controls
- Locally hosted resume and portfolio imagery
- Accessible landmarks, skip navigation, focus states, alternative text, and structured data
- Responsive layouts for desktop, tablet, and mobile screens

## Technology

- Semantic HTML5
- Modern CSS with custom properties, Grid, Flexbox, and responsive media queries
- Vanilla JavaScript for the experience carousel controls
- Google Fonts and externally hosted development-tool icons

## Project structure

```text
.
├── index.html       # Page content, metadata, structured data, and carousel behavior
├── style.css        # Visual system, component styles, and responsive layouts
├── assets/          # Portrait, resume, logos, screenshots, diagrams, and favicon
├── CONCERNS.md      # Open design or content considerations
└── README.md
```

## Run locally

No dependencies or compilation are required. From the repository root, start any
static file server, for example:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).
